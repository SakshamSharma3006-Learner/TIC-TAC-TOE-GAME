## 🧩 About The Project

**Tic Tac Toe** is a modern, interactive and responsive browser-based
game developed using **HTML5, CSS3 and JavaScript**.

The project combines classic Tic Tac Toe gameplay with a modern user
interface, interactive game logic and responsive design.

> 🎯 **Goal:** Build an engaging browser game while strengthening
> real-world JavaScript and front-end development skills.

## ✨ Key Features

| Feature | Description |
|---|---|
| 👥 **Player vs Player** | Play against a friend on the same device |
| 🤖 **Player vs AI** | Challenge the computer |
| 🏆 **Winner Detection** | Automatically detects the winner |
| ➖ **Winning Line** | Highlights the winning combination |
| 📊 **Scoreboard** | Keeps track of player scores |
| 🔄 **Restart Game** | Start a new round instantly |
| 🌓 **Theme Toggle** | Switch between available themes |
| 📱 **Responsive UI** | Works across different screen sizes |
| ⚡ **Lightweight** | Runs directly in the browser |

## 🎮 Game Modes

### 👥 Player vs Player

Challenge a friend and take turns placing **X** and **O** on the board.

### 🤖 Player vs AI

Play against the computer and test your strategy.
